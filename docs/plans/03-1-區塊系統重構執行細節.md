# 區塊系統重構執行細節 (v0.2.0)

> 基於 03-區塊系統重構計劃.md 並配合「廢除獨立圖表」方針

## 一、狀態傳遞協議

為了確保區塊編輯時不丟失儀表板的其他狀態，採用以下協議：

### DashboardEditor -> ChartEditor
```ts
navigate(`/dashboards/edit/${id}/blocks/${blockId}/edit`, {
  state: { 
    returnTo: `/dashboards/edit/${id}`, 
    dashboardConfig: config 
  },
});
```

### ChartEditor -> DashboardEditor
```ts
// 更新對應 block 並返回完整 config
const updatedBlocks = dashboardConfig.blocks.map(b => 
  b.id === blockId ? { ...b, config: currentBlockConfig } : b
);
const updatedDashboardConfig = { ...dashboardConfig, blocks: updatedBlocks };

navigate(returnTo, { 
  state: { config: updatedDashboardConfig } 
});
```
