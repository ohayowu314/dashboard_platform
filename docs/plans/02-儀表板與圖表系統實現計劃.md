# 儀表板與圖表系統實現計劃

> 建立完整的儀表板區塊系統與圖表管理功能

## 一、系統目標

### 儀表板瀏覽模式 (DashboardViewPage)
- 根據設定渲染各種區塊於畫布中
- 區塊與區塊間、區塊與畫布邊界留空，避免擁擠
- 區塊內部用卷軸處理大小變化
- 圖表區塊右上角滑鼠懸停顯示眼睛圖示，點擊導航至圖表編輯頁面

### 儀表板編輯模式 (DashboardEditorPage)
- 從新建或瀏覽模式進入
- 區塊可拖曳、縮放大小、交換區塊位置
- 畫布空白區域 hover 顯示加號按鈕，可新增區塊
- 新增區塊流程：選擇類型 → 進入區塊編輯狀態
- 區塊編輯狀態：
  - 右上角：眼睛、編輯、刪除圖示
  - 點擊編輯：內容替換為設定表單，左上角顯示返回圖示

### 圖表編輯頁面 (ChartEditorPage)
- 上方：左上角返回按鈕、中間圖表名稱與ID
- 中間：三欄佈局
  - 左上：資料表選擇
  - 左下：欄位選擇
  - 中間：圖表即時渲染
  - 右側：圖表類型選擇 + 類型選項
- 無法渲染時：中間顯示暫無結果提示
