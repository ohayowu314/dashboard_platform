# 儀表板平台後續優化與功能擴展計劃 (v0.4.0)

## 一、 細節優化 (Detail Refinement)

### 1. 載入體驗標準化
*   **骨架屏 (Skeletons)**：在儀表板瀏覽或編輯頁面載入期間，使用 MUI Skeleton 模擬佈局，取代單調的 `CircularProgress`，減少頁面閃爍與跳躍感。
*   **漸進式渲染**：優化區塊載入順序，確保介面結構優先呈現。

### 2. 上傳流程優化 (Upload UX)
*   **非同步編輯捷徑**：統一所有上傳流程為「背景處理」，不再於上傳前強制跳轉。
*   **狀態列互動強化**：在 `ExpandableStatusBar` 或上傳狀態面板中，針對成功上傳的單一項目增加「立即編輯」按鈕，點擊後導航至 `DataTableEditorPage` 或 `DashboardEditorPage`。
*   **簡化數據流**：編輯器統一透過 `id` 從後端讀取資料，移除透過路由傳遞 `File` 物件的不可靠路徑。

### 3. 圖表類型選擇圖示化 (Visual Type Selector)
*   **視覺替換**：在 `ChartEditorPage` 中，將目前的純文字按鈕替換為直觀的圖表圖示（如：`TableChart`, `BarChart`, `Timeline`, `PieChart` 等）。
*   **互動提示 (Tooltip/Title)**：增加滑鼠懸停顯示 Tooltip，並在選中圖標後顯示清楚的類型標題。
*   **區塊操作增加圖示**：
    *   **管理選單**：在區塊包裝器上增加「編輯設定」、「複製」、「刪除」的功能圖示。
    *   **拖拽引導**：增加明確的抓取手柄 (Drag Handle) 圖示，提升易用性。

### 4. 移除歷史殘留 (Legacy Cleanup)
*   **程式碼清理**：
    *   徹底移除 `electron`、`shared/types` 以及前端組件中所有與舊版「獨立圖表」相關的殘留程式碼、檔案與資源。
    *   **移除 `useFileParser.tsx`**：由於上傳流程已全面背景化，不再需要於前端解析原始 `File` 物件。
*   **樣式重構**：統一提取重複的樣式定義至全域主題配置。

---

## 二、 核心功能擴展 (Feature Expansion)

### 1. 區塊色彩自定義
*   **配色方案 (Color Palettes)**：在區塊編輯器中加入配色選擇器，提供多套專業的主題色系。
*   **數列調色**：支援針對多指標圖表的單獨數列自定義顏色。

### 2. 資料表架構編輯 (Schema Editor)
*   **欄位編輯**：支援在 UI 上直接對資料表進行欄位增減、重新命名。
*   **型別定義 (Data Typing)**：支援指定欄位資料類型（文字、數值、日期、布林值），並在資料輸入時進行自動格式化或校驗。

### 3. 智慧圖表適應 (Smart Adaptation)
*   **配合資料類型**：圖表編輯器能根據所選欄位的資料型別（例如：時間序列 vs 分類資料）自動推薦最適合的圖表類型或座標軸格式。
*   **動態適應**：切換資料源時，圖表配置能智能保留相容的設定。

### 4. 儀表板匯入與匯出
*   **移植性**：支援將整個儀表板（含設定與資料架構）匯出為標準化格式，並能透過匯入功能在不同環境快速部署。

---

## 三、 超進階視覺與體驗 (Advanced Evolution)

### 1. 更多圖樣變化
*   **複合與堆疊圖**：支援在單一區塊內混合不同圖表類型（如：柱狀圖 + 折線圖），以及增加堆疊 (Stacked) 或百分比堆疊顯示。
*   **動態轉場**：增加更細膩的資料變動動畫，提升大屏展示視覺效果。

### 2. 整體明暗模式 (Theme Engine)
*   **全域主題切換**：整合全域 Light/Dark Mode 切換功能。
*   **圖表自動調適**：圖表的背景、格線、軸線與預設配色將隨明暗模式自動反轉，確保在任何模式下皆具備最佳閱讀性。

---

## 四、 系統導航與入口優化 (Navigation & Entry Optimization)

### 1. 首頁動態導入與預設儀表板管理
*   **動態渲染邏輯 (Homepage Logic)**：
    *   **引導模式 (Onboarding Mode)**：若系統中無任何儀表板（`DashboardCount === 0`），顯示藝術化歡迎頁面。
    *   **效率模式 (Dashboard Mode)**：若已有儀表板，自動載入「指定預設儀表板」或「首個儀表板」的瀏覽模式（View Mode）。
*   **引導介面設計 (Welcome Screen)**：
    *   **品牌識別**：中心化配置 Logo (`public\snake.png`) 與具備藝術美感的歡迎語（例如：「開啟您的數據洞察之旅」）。
    *   **引導動作**：提供清楚的快速連結，導向「資料表管理 (`/data-tables`)」與「儀表板管理 (`/dashboards`)」。
*   **預設設定與管理 (Persistence)**：
    *   **自定義預設值**：在儀表板管理列表中，增加「設為預設」操作入口。
    *   **持久化策略**：在系統層級紀錄 `defaultDashboardId`，並在預設項目遺失時具備自動降級（Fallback）至列表首項的處理機制。
