# 區塊系統重構計劃

> 記錄時間: 2026-04-19

---

## 一、背景與目標

### 原有問題

| 問題 | 說明 |
|------|------|
| 區塊編輯範圍狹窄 | 彈出面板太小，UI/UX 不佳 |
| 跳轉後狀態丢失 | 先調整大小/位置，再跳 ChartEditor，返回後變更消失 |
| 圖表獨立存儲意義不大 | 建立圖表後還要回來選擇，流程繁瑣 |
| 文字區塊單獨存在意義低 | 純文字不如直接放在圖表區塊內 |

### 目標

1. **廢除文字區塊** - 單純文字沒有意义
2. **合併表格與圖表** - 用 chartType 區分顯示類型
3. **大型編輯頁面** - 三欄布局，左（資料表）/ 中（即時預覽）/ 右（設定）
4. **跳轉保持狀態** - 通過 React Router state 傳遞 config

## 二、資料結構

### TypeScript Discriminated Union

```ts
// ChartType 擴展
type ChartType = "table" | "bar" | "line" | "pie" | "scatter" | "histogram" | "area";

// 共同基礎
interface BaseChartBlockConfig {
  id: string;
  title?: string;
  description?: string;
  dataTableId: number;
}

// 表格類型
interface TableChartBlockConfig extends BaseChartBlockConfig {
  chartType: "table";
  columns?: string[];
  pageSize?: number;
  sortable?: boolean;
}

// 圖表類型
interface ChartChartBlockConfig extends BaseChartBlockConfig {
  chartType: "bar" | "line" | "pie" | "scatter" | "histogram" | "area";
  xAxis: string;
  yAxis: string | string[];
  options?: ChartDisplayOptions;
}

// 完整類型
type ChartBlockConfig = TableChartBlockConfig | ChartChartBlockConfig;
```

### DashboardBlock 簡化

```ts
interface DashboardBlock {
  id: string;
  layout: { x: number; y: number; w: number; h: number };
  config: ChartBlockConfig;
}
```

## 四、新增的路由與流程

### 路由設計

```
/dashboards/edit/:id/blocks/:blockId/edit
```

### 流程

```
1. DashboardEditorPage
   │
   ▼ 新增區塊
2. 新增 chart config (chartType = "bar", dataTableId = 0)
   │
   ▼ 點擊編輯
3. navigate("/dashboards/edit/:id/blocks/:blockId/edit", { state: { config } })
   │
   ▼ ChartEditorPage (全版三欄)
   - 左：資料表選擇、欄位選擇
   - 中：即時渲染預覽
   - 右：標題、描述、類型、選項
   │
   ▼ 儲存
4. navigate(returnTo, { state: { config } })
   │
   ▼ DashboardEditorPage
5. config 已更新
```

### 跳轉保持狀態

```tsx
// DashboardEditorPage -> ChartEditorPage
navigate(path, {
  state: { 
    returnTo: `/dashboards/edit/${id}`,
    config: currentConfig
  }
});

// ChartEditorPage -> DashboardEditorPage
navigate(returnTo, {
  state: { config: savedConfig }
});
```
